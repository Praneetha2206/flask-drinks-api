Flask Drinks REST API
A simple REST API built with Python, Flask, Flask-SQLAlchemy, and SQLite. This project demonstrates basic CRUD operations for managing drinks.
Features:
1.Retrieve all drinks
2.Retrieve a drink by ID
3.Add new drinks using POST requests
4.Store drink data in an SQLite database
5.Use SQLAlchemy ORM for database operations
Tech Stack:
1.Python
2.Flask
3.Flask-SQLAlchemy
4.SQLite
